TryHackMe Cybersecurity Journey
About This Repository

This repository documents my hands-on cybersecurity learning journey through TryHackMe, with a focus on Security Operations Center (SOC) analysis and defensive security.

The goal is to consolidate my technical knowledge, document investigation methodologies, and demonstrate practical cybersecurity skills through write-ups, notes, and relevant screenshots.

Areas of Focus
SOC Fundamentals — SIEM concepts, log analysis, alert triage, and security monitoring.
Phishing Analysis — Email investigation, malicious URL identification, and email header analysis.
Network Traffic Analysis — Packet inspection, DNS analysis, and suspicious network activity.
Malware Analysis — File analysis, malware behavior, and indicators of compromise (IOCs).
Threat Intelligence — IOC enrichment, threat research, and MITRE ATT&CK mapping.
Incident Response — Incident investigation, documentation, and containment strategies.

Learning Methodology

For each topic or room, I aim to document:

Overview — Key concepts and learning objectives.
Tools Used — Tools and technologies explored.
Methodology — Investigation steps and techniques applied.
Evidence — Relevant screenshots and supporting artifacts.
Findings — Observations, analysis, and conclusions.
Key Takeaways — Lessons learned and practical applications.
